## 日本 VPS 的“推荐”到底在推荐什么

一句话答案：推荐的是线路类型和 IP 属性，机房在东京只是入场券。

同样一个东京机房，走三网优化线路和走普通国际线路，国内访问延迟能差出两三倍。普通国际线路绕道欧美或东南亚，延迟轻松过 150ms；走优化直连的，国内到东京通常在 70–100ms。这个差距在视频上传、游戏、后台操作里是完全不同的体验。

常见的日本线路有这么几类：

- **CN2 GIA**：电信的高端骨干，电信用户体验最好，高峰期延迟波动小。移动和联通走这条增益有限。
- **AS9929**：联通的优化线路，联通用户快，对移动也有帮助，电信反而不如 CN2 GIA。
- **CMIN2**：移动的国际优化线路，比传统的 CMI 更新，持续吞吐表现更稳。
- **三网优化**：上面三条各走各的，电信走 CN2、联通走 9929、移动走 CMIN2。三家都有改善，是目前最均衡的选法。
- **ISP 住宅原生 IP**：跟线路无关，说的是 IP 属性。IP 模拟真实日本家庭宽带用户，平台风控识别时信任度更高。

GoMami 的日本节点走的是第四条：去程主线直连，回程电信 CN2、联通 AS9929、移动 CMIN2/CMI，官方说法是“按源 IP 自动选最优回程 + 多上游冗余自动故障切换”。

至于第五条，那是另一类产品。做日区账号运营需要的是住宅 IP，机房 IP 再快也解决不了这个问题。

## 实测数据：电信联通能跑满，移动上行会被限速

先给结论：电信和联通单线程能稳定跑到 400Mbps 以上；移动去程上行被限速得比较严重，下行正常。

2025 年 12 月有人拿 JPN.Pulse.Mini 做过一轮 iperf3 实测，几组数字比较能说明问题：

| 测试来源 | 上行 | 下行 |
| --- | --- | --- |
| 深圳电信 500Mbps | 404–417 Mbits/sec | 正常 |
| 济南联通 500Mbps | 358–545 Mbits/sec | 正常 |
| 广东移动 1Gbps | 35.6 Mbits/sec | 174 Mbits/sec |
| 武汉移动 1Gbps | 43.0 Mbits/sec | 433 Mbits/sec |
| 宁波移动 500Mbps | 33.9 Mbits/sec | 568 Mbits/sec |

移动这一列很直白：上行三十几 Mbps，下行看运气从 170 到 570 不等。同一轮测试里电信和联通是满速跑的状态。

另一组东京本地的 Speedtest 结果也印证了这一点：东京本地节点 996.65 / 945.71 Mbps、延迟 1.74ms，说明机器本身的出口没问题；上海联通 5G 195.15 / 87.91 Mbps、54.19ms，浙江电信 198.27 / 86.55 Mbps、56.10ms，苏州电信 5G 293.37 / 75.95 Mbps、56.74ms。延迟落在 54–57ms，跟官方标称的 < 50ms 接近。

**测这台机器的那位测试者，按运营商给出的排序是：电信香港 ≈ 日本 > 新加坡，联通香港 > 日本 > 新加坡，移动新加坡 > 日本 ≈ 香港。** 也就是说，移动方向上香港和日本的上行被 QoS 的程度差不多，真正拉开差距的是新加坡——同一轮测试里新加坡的移动方向表现最好。如果你主要是移动用户、业务又上下行对称（直播推流、实时对战、大文件上传），优先考虑 SIN Pulse，而不是在香港和东京之间二选一。

还有一条容易被忽略：**东京到香港之间被非对称限速。** 同一台机器测香港节点，结果是 0.07 / 6.09 Mbps、48.06ms。这不是数据写错，是策略。如果你有香港方向的流量，直接买香港节点，别想着从东京绕。

CPU 和磁盘方面，2025 年那轮 LemonBench Fast Mode 跑出单核 3,676、双核 7,361。fio 4K 随机读写各 260 MB/s 左右、合计约 130k IOPS；64K 顺序 2.14 / 2.15 GB/s，1M 顺序 4.96 / 5.29 GB/s。这组数字对建站和常规数据库负载够用。

需要说明的是，那轮测试的机器当时标注是 40GB 硬盘，和现在官网的 60GB 不一样，可能对应早期配置。数字可以用来看性能水位，别当成当前规格。

## 几条不写在首页上的限制

首页写的是“最高 600 Gbps DDoS 防护”和“< 50ms 延迟”。真正会影响你决策的几条，藏在官方 FAQ 和退款政策里。

**DDoS 防护默认是 best-effort，600 Gbps 是付费附加项。** 官方 FAQ 的原话是：所有实例默认提供尽力而为的防护，自动检测和清洗，正常流量不受影响；当攻击波及其他客户时，IP 会被黑洞 30–60 分钟，自动释放，无法人工干预。想要更强的清洗能力，600 Gbps 那一档需要额外付费。不少介绍文章把 600 Gbps 直接写成“自带防护”，这个说法不准确。

顺带一条：因 DDoS 攻击导致 IP 被牵引的情况**不支持退款**。

**超流量是限速，不是收超量费。** 官方 FAQ 只说“超出月配额后带宽可能被限速，具体策略取决于产品规格”，没给具体数值。第三方资料给出的数字是 20 kb/s，直到下个计费周期，不产生额外账单，额度在每个周期开始时重置。需要临时加流量可以单独买流量包，不用升级套餐。

**到期即暂停，没有宽限期。** 到期日当天服务立即暂停（数据保留，续费后自动恢复），逾期 5 天终止，数据可能不可恢复。没有“再给你三天”这回事。

**退款窗口只有 24 小时。** 新购 24 小时内可无理由全额退款；超过 24 小时不退，续费订单不退，已使用的余额不退。退款到账时间：支付宝 1–3 个工作日，信用卡 5–10 个工作日，加密货币 1–3 个工作日。审核通过后实例和数据会立即永久删除，申请前先备份。
